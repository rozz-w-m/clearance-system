# Student Clearance Form Generator

This project is a web-based **Student Clearance Form Generator** built with **React** and **TypeScript**, allowing school administrators to manually fill out and generate downloadable PDF clearance forms for student transfers.

-NOTE: No backend intergrated

## Project: Clearance Form System

This app provides an easy-to-use interface for entering:
- Student information
- Fee balances
- Unreturned books
- Laboratory damages
- Date of clearance

It then generates a structured **PDF clearance form** that can be saved and printed.

---

## Features

- Dynamic form with real-time validation
- Add/remove books not returned
- Add/remove lab damages
- PDF generation with school header and student details
- Downloadable and printable output
- Clean and responsive UI

---

## Tech Stack

- **React** (with Hooks)
- **TypeScript**
- **jsPDF** – For PDF generation
- **CSS** – Custom styling
